Book Status & Production Updates
Stages: Manuscript Received → Editing (if opted) → Cover Design → Typesetting → Proofreading → ISBN Assignment → Printing → Distribution Setup → Published & Live.
Authors are emailed at each stage. Typical delays: Cover Design (waiting on author approval) and Proofreading (revision rounds).
Be honest about the actual stage. If delayed, say why. Do not blame the author even if they are the blocker — frame it as a shared next step.

Q: It has been 3 weeks and the book is still in typesetting.
A: Check the real production status. If delayed, be honest. Give a specific updated timeline.
